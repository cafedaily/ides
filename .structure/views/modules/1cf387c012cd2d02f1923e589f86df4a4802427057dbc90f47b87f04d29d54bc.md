## Current truths

- Fresh startup contains no demo data or bundled model. A user creates an empty independent local space, configures their own OpenAI-compatible model, then creates ideas.
- IndexedDB stores all space content and model keys on the current device. Navigation-only changes do not create revisions; atomic local revisions protect against concurrent-window overwrites and drafts remain in sessionStorage.
- Model calls go directly to the configured provider with CORS, omitted cookies, no referrer and no redirects. No frontend /api calls or implicit server model fallback exist.
- Settings use explicit model saves/tests, default and per-action model selection, local JSONL import/export and responsive light/dark layouts. Plain exports redact keys; encrypted exports include them.
- Lexical bridges and paths are calculated in local_graph.js without uploading documents. The historical Python graph benchmark is not a performance claim for this browser implementation.

## Don't assume

- Do not treat local persistence as offline inference: remote model requests send selected text to the user-chosen provider.
- Do not delete or silently import legacy user data.
