## Current truths

- POST /api/chat with body stream:true is handled by the HTTP server after private-route authentication and same-origin mutation checks, returning text/event-stream with no-store, X-Accel-Buffering:no and flushed JSON SSE events.
- Chat upstream requests are OpenAI-compatible; non-stream requests remain buffered JSON responses, while stream requests send stream:true upstream and relay upstream SSE deltas incrementally as {type:"delta",text}, {type:"done"}, or sanitized {type:"error",error}.

- Production auth policy always uses Secure session cookies even if YANG_AUTH_SECURE_COOKIE=0; unsupported Transfer-Encoding and invalid Content-Length/body framing are rejected and the connection is closed.
