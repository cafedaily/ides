# 养想法 — 项目全局状态

> 最后更新：2026-09-11

## 是什么

一个人的想法空间。念头进来，被追着问，慢慢长出形状；长不出来的，留下一句「为什么」。
后端把所有想法拆成关键词，建成一张二部图，再把不同维度上的东西串起来。

## 核心闭环

```
念头 → 养起来（起名 + 第一问）→ 被追问 / 换角度 / 碰一下 / 分叉
     → 后端抽词建图 → 桥和路径告诉你「这个想法其实在说另一个想法的事」
     → 顺着那条线回去接着答
```

## 技术栈选择

| 选择 | 原因 |
|---|---|
| 零第三方依赖 | 起不来的可能性最小；一台干净的机器装个 Python 就能跑 |
| 滑动二元组而不是词典分词 | 不用维护词典；代价是噪声多，靠停用表和 TF-IDF 压 |
| 跨语料实体归并 | 弥补逐段分词看不见的多字实体（`定期见面的理由`） |
| 凝固度而不是邻接熵 | 小语料（几十篇）上熵估不准，凝固度只要两个计数 |
| 后端代理调 LLM | 绕 CORS、藏 API key；没模型退回内置题库 |
| 全量推送 | 少一整类「两边不一致」的 bug；几十篇够用 |
| SQLite 单文件 | 拷走就是全部数据；没有服务要起 |
